인증 및 데이터 흐름

원칙: ai-engine은 "누가·권한"을 모른다

• 계약 조회 필요 → Spring이 페이로드로 전달
• MCP 도구는 신원 불필요 것만 노출 (약관 검색)
• A2A 스킬은 Spring이 호출자 검증 후 ai-engine 호출

이점: 권한 사고 표면 제로, 테스트·CI 환경에서 웹 없이 순수 Python 실행 가능

제안: 거부 상태 추가 (구현 대기)

현재: 모든 스킬 `status`가 `["completed"]` 단일값
문제: "근거 없음"을 표현할 방법이 없음

제안 (A2A_Q 합의 필요):
status: "rejected", rejection_reason: "no_evidence_found|citation_unverified"
HTTP 200 (거부는 정상 동작, 4xx/5xx 아님)
